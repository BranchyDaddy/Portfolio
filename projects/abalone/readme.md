# Задача проекта

Построить модель машинного обучения для **предсказания возраста моллюсков Abalone** (морское ушко) на основе их физических измерений.

**Целевая переменная:** `Rings` — количество колец на раковине.  
Возраст (в годах) = `Rings + 1.5`

**Входные данные:**
- `Sex` — пол (M, F, I — инфантильный)
- `Length` — длина раковины, мм
- `Diameter` — диаметр (перпендикулярно длине), мм
- `Height` — высота с мясом в раковине, мм
- `Whole weight` — общий вес, граммы
- `Shucked weight` — вес мяса, граммы
- `Viscera weight` — вес внутренностей, граммы
- `Shell weight` — вес сухой раковины, граммы

**Этапы работы:**

1. **Разведочный анализ данных (EDA)**
2. **Построение модели**
3. **Деплой в докер результатов модели**

**Образ можно использовать, выполнив `docker pull parmedocker/abalone_dashboard`**
