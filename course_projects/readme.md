# Учебные работы по Data Science

Этот папка содержит проекты, выполненные в рамках курса по анализу данных и машинному обучению. Каждый проект представляет собой Jupyter Notebook и демонстрирует применение различных методов и библиотек для решения конкретных задач.

---

## 1. Визуализация данных (EDA) и проверка гипотез

### Анализ рейтингов фильмов (Fandango)
**Файл:** `Visualisation Project - Jupyter Notebook.pdf`

**Цель:** Выяснить, завышала ли компания Fandango рейтинги фильмов в 2015 году для стимулирования продаж билетов.

**Краткое описание:**
Проект фокусируется на исследовательском анализе данных (EDA). Сравниваются рейтинги Fandango с оценками других платформ (Rotten Tomatoes, Metacritic, IMDB). С помощью визуализаций (гистограммы, диаграммы рассеяния, KDE-графики) демонстрируется, что распределение оценок Fandango смещено в сторону более высоких значений по сравнению с другими источниками. Также проводится анализ разницы между отображаемыми звездами (`STARS`) и реальным рейтингом (`RATING`).

**Ключевые навыки:** `Python` (Pandas, Matplotlib, Seaborn), EDA, визуализация данных, проверка гипотез.

## 2. Линейная регрессия

### Прогнозирование цен на жилье (Ames Housing)
**Файл:** `LR Ames Housing - Jupyter Notebook.pdf`

**Цель:** Построить модель линейной регрессии (ElasticNet) для прогнозирования стоимости домов на основе набора признаков из датасета Ames Housing.

**Краткое описание:**
Выполнена предобработка данных, включая масштабирование признаков (`StandardScaler`). Для обучения модели и подбора гиперпараметров (alpha, l1_ratio) использован `GridSearchCV` с кросс-валидацией. Итоговая модель оценивается на тестовой выборке по метрикам MAE и RMSE.

**Ключевые навыки:** `Python` (Pandas, Scikit-learn), линейная регрессия, ElasticNet, масштабирование данных, подбор гиперпараметров (GridSearchCV), оценка моделей регрессии.

## 3. Логистическая регрессия

### Обнаружение сердечных заболеваний (Heart Disease Detector)
**Файл:** `LogR Heart Desease Detector - Jupyter Notebook.pdf`

**Цель:** Разработать модель бинарной классификации для прогнозирования наличия сердечного заболевания у пациента на основе его медицинских показателей.

**Краткое описание:**
Проведен исследовательский анализ данных с визуализацией корреляций и распределений. Построена модель логистической регрессии с регуляризацией (`LogisticRegressionCV`). Модель автоматически подбирает параметр регуляризации C. Произведена оценка качества модели по метрикам точности, полноты и F1-меры, а также построена матрица ошибок и ROC-кривая. В конце показан пример предсказания для нового пациента.

**Ключевые навыки:** `Python` (Pandas, Seaborn, Scikit-learn), логистическая регрессия, классификация, бинарная классификация, оценка моделей (матрица ошибок, ROC-AUC), интерпретация коэффициентов.

## 4. Метод k-ближайших соседей (KNN)

### Обнаружение мин (Mines Detector)
**Файл:** `KNN Mines Detector - Jupyter Notebook.pdf`

**Цель:** Классифицировать подводные объекты как "мина" (M) или "камень" (R) на основе данных сонара.

**Краткое описание:**
Задача бинарной классификации на основе 60 признаков (частот). Выполнена предобработка данных, включая масштабирование. Использован алгоритм K-ближайших соседей (KNN) в связке с `GridSearchCV` для выбора оптимального числа соседей (k) по метрике accuracy. Визуализированы результаты подбора гиперпараметра и произведена итоговая оценка модели на тестовой выборке.

**Ключевые навыки:** `Python` (Pandas, Scikit-learn), KNN, классификация, подбор гиперпараметров, пайплайны (`Pipeline`).

## 5. Метод опорных векторов (SVM)

### Классификация вин на подлинные и поддельные (Wine Fraud Detection)
**Файл:** `SVM Wine Classification - Jupyter Notebook.pdf`

**Цель:** На основе химических тестов определить, является ли вино настоящим или поддельным.

**Краткое описание:**
Классическая задача с сильным дисбалансом классов (всего ~4% подделок). Выполнен анализ данных, выявлены корреляции. Обучена модель SVM с подбором гиперпараметров (C, kernel, gamma, degree) через `GridSearchCV`. Продемонстрирована и объяснена опасность использования accuracy при дисбалансе классов. Сделаны выводы о непригодности модели для реального применения из-за низких показателей precision и recall для класса мошенничества.

**Ключевые навыки:** `Python` (Pandas, Scikit-learn), SVM, работа с дисбалансом классов, подбор гиперпараметров, критическая оценка моделей и метрик.

**Цель:** Построить модель для прогнозирования оттока клиентов телекоммуникационной компании.

Произведена оценка модели по метрикам классификации. На основе важности признаков (`feature_importances_`) и результатов EDA сформулированы бизнес-рекомендации для удержания клиентов.

## 7. Кластеризация (KMeans)

### Кластеризация стран (Countries Clustering)
**Файл:** `Kmeans Countries Clustering - Jupyter Notebook.pdf`

**Цель:** Сгруппировать страны по социально-экономическим показателям, найдя оптимальное количество кластеров.

**Краткое описание:**
Выполнена предобработка данных, включая заполнение пропусков и стандартизацию (`StandardScaler`). Применен алгоритм KMeans. Для определения оптимального числа кластеров использованы метод локтя (inertia) и коэффициент силуэта (silhouette score). Проанализирована связь полученных кластеров с исходными категориальными признаками, такими как регион.

**Ключевые навыки:** `Python` (Pandas, Scikit-learn), KMeans, обучение без учителя, определение оптимального числа кластеров, метод локтя, силуэт.

## 9. Метод главных компонент (PCA)

### Анализ рукописных цифр (Handwritten Digits PCA)
**Файл:** `PCA Project - Jupyter Notebook.pdf`

**Цель:** С помощью метода главных компонент уменьшить размерность данных и визуализировать структуру набора изображений рукописных цифр.

**Краткое описание:**
Данные представляют собой изображения рукописных цифр размером 8x8 пикселей (64 признака). После стандартизации признаков применен PCA. Построены 2D и 3D графики проекций точек. Это позволило визуально оценить, какие цифры наиболее хорошо разделяются в пространстве главных компонент (например, цифра 4).

**Ключевые навыки:** `Python` (Pandas, Scikit-learn, Matplotlib), PCA, уменьшение размерности, визуализация многомерных данных, работа с изображениями.
