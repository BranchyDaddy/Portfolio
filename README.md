## 📌 О портфолио

В этом репозитории собраны проекты, выполненные в рамках:
- университетских лабораторных работ (`edu_projects`)
- курсовой работы (`kursach`)
- онлайн-курса по анализу данных и машинному обучению (`ml_course_projects`)
- пет-проектов (`projects`)

Каждая работа демонстрирует практическое применение навыков в области анализа данных и машинного обучения.

---

## 📁 Структура репозитория

| Папка | Описание |
|-------|----------|
| [`diplomas`](./diplomas) | Сертификаты и дипломы, подтверждающие навыки в области программирования, анализа данных и машинного обучения |
| [`edu_projects`](./edu_projects) | Лабораторные работы из университета: EDA, регрессия, классификация, NLP, анализ оттока клиентов |
| [`kursach`](./kursach) | Курсовая работа: построение и сравнительный анализ моделей ML для многоклассовой классификации кредитного скоринга |
| [`ml_course_projects`](./ml_course_projects) | Проекты с онлайн-курса по анализу данных и машинному обучению |
| [`projects`](./projects) | Пет-проекты — самостоятельные работы для отработки навыков и исследования интересных задач |
